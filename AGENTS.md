## Site notes
- Vercel auto-deploys `main` (project `noor-hossain-portfolio`, static site, no build step).
- Reply to Noor in Banglish.
- Default theme is light; dark is opt-in via the toggle.
- Security headers + hash-based CSP live in `vercel.json`, generated by `scripts/csp.py`.
  After editing ANY inline `<script>` in `index.html`, run `python3 scripts/csp.py`
  or the script will be blocked in production.
- "Latest projects" is an Orbix-style 3-column grid (same light-grey cover bg, hover shows a cursor ellipse with the project name, click opens it). Cards are generated from `scripts/projects.py` (cover styles:
  frame/macbook/imac/tablet/browser/angle, full-page screenshots that scroll on hover). Run `python3 scripts/projects.py index.html` (it also re-runs csp.py); full-page screenshots live in `assets/work/shots/<slug>-full.webp`. Do not move the section.
- Section spacing: every section uses the standard `section` padding; only add
  `padding-top:0` when the previous section is a plain (non-card) section, so gaps stay consistent.
